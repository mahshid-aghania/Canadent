Static mirror of https://canadent.net
Captured: 2026-07-24

Security hardening:
- Removed remote tracker/badge/analytics scripts (TrustedSite, GoDaddy wsimg,
  Jetpack stats, Stripe.js, Woo analytics clients).
- Neutralized hijack/spam doorway URL patterns (including *.shop/?utm_term=...).
- Rewrote absolute https://canadent.net/... URLs to root-relative local paths
  so the mirror does not phone home to the live WordPress site.
- Added Content-Security-Policy on HTML pages: self-only scripts/styles/images,
  connect-src none, frame-src none.

Note: yx9belqoni.yx9belqoni.shop is a known malware-redirect domain used in
WordPress redirect campaigns. It was not present as a stored string in the
static files, but absolute live-site links could still load infected responses
from production. Those live links are now localized/blocked.

Browse offline:
  cd site && python3 -m http.server 8080
